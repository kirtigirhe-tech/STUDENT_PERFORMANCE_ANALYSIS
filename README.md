# Student Performance Analysis

## 📌 Project Overview

This project analyzes student academic performance using Python and Pandas.
The analysis focuses on subject-wise marks, total marks, percentage,
grades, attendance, and pass/fail status.

The processed data is exported to a CSV file and further used to create
a Power BI dashboard for visualization and analysis.

## 🎯 Objectives

- Analyze student performance across different subjects
- Calculate total marks and percentage
- Assign grades based on student percentage
- Determine Pass/Fail status
- Analyze student attendance
- Identify highest and lowest percentages
- Calculate average student performance
- Create a Power BI dashboard for visualization

## 🛠️ Tools & Technologies

- Python
- Pandas
- Power BI
- CSV
- Data Analysis
- Data Visualization

## 📊 Analysis Performed

The Python program performs the following operations:

1. Creates a student performance dataset
2. Converts the data into a Pandas DataFrame
3. Calculates total marks
4. Calculates percentage
5. Assigns grades based on percentage
6. Determines Pass/Fail status
7. Calculates average percentage
8. Identifies the highest percentage
9. Identifies the lowest percentage
10. Calculates average attendance
11. Exports the processed data to a CSV file

## 📈 Key Results

|---|---:|
